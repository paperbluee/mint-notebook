# 薄巧 · 四六级单词默写本

将本目录里的文件上传到 GitHub 仓库根目录。进入仓库的 **Settings → Pages**，选择 **Deploy from a branch → main → /(root)**，点击 **Save**。发布后，Pages 设置页会显示访问链接。

在 iPad 上用 Safari 首次联网打开该链接，通过「分享 → 添加到主屏幕」安装。保持联网，从主屏幕打开，等待「已可离线使用」，即可关掉网络。切换词表、默写、批改和次日复习都在设备上进行。原网站的记录保存在原地址的浏览器存储中。

本网站将两套内置词表、界面资源和离线代码一同发布。四级词表的 ECDICT 许可见 ecdict-license.txt。六级内置词表是独立编写的六级练习词，支持自行导入教材词表。
